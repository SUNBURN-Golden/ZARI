# Easy Mode 최종 문구 — 2026-11-03

사용자 지정 표 `copy-argon-real.md`의 22개 항목과 PR #129 적용 예외를 반영한다. 문구 확정은 화면 baseline 승인을 뜻하지 않는다.

| 항목 | 적용 문구 |
|---|---|
| 첫 문장 | 물건이 들어갈지 함께 확인해요. |
| 검색 | 어떤 물건을 놓으시나요? (예: 수납함, 전자레인지, 책장) |
| 입력 도움 (물건) | 물건의 가장 튀어나온 곳을 기준으로 재 주세요. |
| 입력 도움 (공간) | 놓을 곳의 안쪽을 재 주세요. 세로는 앞뒤 깊이예요. |
| 단위 확인 | 혹시 mm로 재셨나요? / cm로 잰 숫자가 맞는지 확인해 주세요. / 네, cm가 맞아요 |
| 보조 버튼 | 다음으로 / 결과 보기 / 다른 물건 해보기 / 처음으로 / 이전으로 |
| 입력 오류 | 가로·세로·높이를 모두 적어 주세요. / 놓을 곳을 골라 주세요. |
| 예제 안내 | 연습 화면이에요. 내 물건은 직접 재서 적어 주세요. |
| 계산 중 | 들어갈 수 있는지 맞춰 보고 있어요. |
| 확인 불가 | {방향} 길이를 다시 적어 주세요. |
| 결과 범위 | 적어 주신 크기대로만 맞춰 본 결과예요. |
| 방향별 여유 | {방향}으로 {치수}cm 남아요 |
| 결과 안내 | 문이 잘 열리는지, 넣고 빼기 편한지는 따로 살펴봐 주세요. |
| 추가 확인 | 사용하지 않음. 결과 화면에는 결과 안내 한 줄만 표시한다. |
| 상세 | 적어 주신 방향 그대로 맞춰 봤어요. 돌려서 넣는 건 빼고 봤어요. |
| 상세 그림 | 점선은 놓을 곳, 실선은 물건 크기예요. |
| 상세 표 | 크기 비교(cm) / 방향 / 물건 / 놓을 곳 / 아직 안 잼 |
| 상세 범위 | 문 열릴 자리나 손이 닿는지는 빼고, 딱 물건 크기만 맞춰 봤어요. (자세히 보기 안에서만 표시) |
| 저장 오류 | 기록을 남기지 못했어요. 화면을 닫기 전에 숫자를 따로 적어 두세요. |
| 계산 오류 | 결과를 불러오지 못했어요. 이전으로 가서 다시 해 주세요. |
| 보조기기 레이블 | 전체 4단계 중 {단계}번째 / 물건 {방향} / 놓을 곳 {방향} / 찾은 물건 / 놓을 곳 |
| 줄자 그림 | 안쪽을 기준으로 가로(왼쪽~오른쪽), 세로(앞~뒤), 높이(아래~위)를 재 주세요. |
