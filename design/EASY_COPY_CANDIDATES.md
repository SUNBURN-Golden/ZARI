# Easy Mode copy-todo — 2026-11-02

상태: copy-todo. 사용자가 명시한 질문·버튼·결과 예시 이외의 아래 보조 문구는 미확정이다. EasyMode의 `data-copy-todo="supporting-copy"`가 이 범위를 표시한다. 아래 문구를 승인으로 기록하지 않는다. 실행 산출물 `/workspace/shots/zari-easy/copy-candidates.md`에도 복사한다.

- 첫 문장: 물건이 들어갈지, 함께 확인해요.
- 검색: 물건 검색 / 물건 이름을 적어 주세요 / 수납함·전자레인지·서랍장·책장·세탁기 (이름 검색 예시, 상품 검색 아님)
- 입력 도움: 물건의 가장 긴 부분을 재 주세요.
- 입력 도움: 물건을 둘 곳의 안쪽을 재 주세요. 세로는 앞에서 뒤까지예요.
- 단위 확인: cm로 잰 값인지 한 번 더 확인해 주세요. / cm로 잰 값이 맞아요
- 보조 버튼: 다음 / 결과 보기 / 더 확인하기 / 뒤로가기
- 입력 오류: 가로·세로·높이를 모두 적어 주세요. / 둘 곳을 골라 주세요.
- 예제 안내: 연습용 예제예요. 실제 물건의 치수는 직접 재 주세요.
- 계산 중: 크기를 확인하고 있어요.
- 확인 불가: 치수를 확인해 주세요 / {방향} 치수를 확인해 주세요
- 결과 범위: 입력한 크기와 방향 기준이에요.
- 방향별 여유: {방향} {치수}cm 남아요
- 결과 안내: 문 열기·설치·꺼내기는 따로 확인해 주세요.
- 추가 확인: 문 여는 공간·여유 간격은 크기 확인에 포함하지 않아요. 문이 열리고 물건을 꺼낼 수 있는지도 따로 확인해 주세요.
- 상세: 입력한 방향 그대로 확인했어요. 돌려서 넣는 방법은 확인하지 않았어요.
- 상세 그림: 입력한 물건과 빈 공간의 크기 그림 / 점선은 빈 공간, 실선은 물건이에요.
- 상세 표: 크기 비교 (cm) / 방향 / 물건 / 빈 공간 / 미확인
- 상세 범위: 문 여는 공간·설치·접근·측정 오차는 아직 확인하지 않았어요. 여유 간격은 더하지 않았어요.
- 저장 오류: 이 기기에 저장하지 못했어요. 화면을 닫기 전에 치수를 따로 적어 주세요.
- 계산 오류: 계산을 마치지 못했어요. 뒤로 가서 다시 확인해 주세요.
- 보조기기 레이블: 4단계 중 {단계}단계 / 물건 {방향} / 빈 공간 {방향} / 물건 검색 결과 / 둘 곳
- 줄자 그림: 줄자로 빈 공간을 재는 방법 / 안쪽 왼쪽부터 오른쪽이 가로, 앞에서 뒤가 세로, 아래에서 위가 높이예요.

원문 지시의 ‘들어가요 / 아슬아슬해요 / 안 들어가요’, ‘혹시 mm로 재셨나요?’, 질문 3개, 방 이름, 지정 결과 버튼·모드 링크·예제 보기·시작하기·자세히 보기는 지시대로 사용한다. 치수 값은 실측 결과이며 문구 승인을 뜻하지 않는다.
