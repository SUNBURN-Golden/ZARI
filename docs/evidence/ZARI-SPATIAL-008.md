## Contract-change advisory

Reviewers should treat this as an additive protocol change plus a build-id bump. `groupFormatRequests` is optional. `formattedGroups` is required on `normalized`. The page and the Worker must move together: `zari-domain-4` is `version_mismatch`, and a reordered capability list is `protocol_version_mismatch`. Persisted schema version 1 is not migrated. The query DTO is not in the generated contract.

## Deviations

- Space diagnostic paths stay `space.{spaceId}.…`, which is the existing normalizer. The route grammar omits the space id. Group formatting treats those two spellings as the same field.
- The frozen fact key is `{entityId}:{fieldPath}` and is not an `Id`. An `Id` rejects `.` and stops at 96 bytes.
- The classifier does not emit `missingNominal`, `missingBound`, or `missingEvidence`. Those names exist on the frozen need enum for SP-010. SP-008 emits `conflictingEvidence` only for reason `conflicting_sources`, plus `repairKnownFailure` and `unsupportedInput`.
- An interval that overflows i64 cannot occur for a value already inside PositionMm and ClearanceMm. The wire overflow fixture is the digit string `9223372036854775808` (`numeric_overflow`). The checked primitive is unit-tested at `i64::MIN` and `i64::MAX`.
- The client previously accepted any capability list with the same members and length. It now requires the same order.
